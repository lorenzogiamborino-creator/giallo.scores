# Giallo Indumentaria 🎨

Tienda oficial de indumentaria deportiva desde Mataderos, Buenos Aires.

## Características ✨

### 1. **Home Page**
- Presentación elegante y moderna
- Destacados de la marca
- Call-to-action directo a tienda y editor de diseños

### 2. **Tienda Online (Shop)**
- Catálogo completo de productos
- Camisetas, shorts, buzos y accesorios
- Carrito de compras persistente (localStorage)
- Interfaz intuitiva

### 3. **Carrito de Compras**
- Agregar/eliminar productos
- Cambiar cantidades
- Cálculo automático de envíos
- Resumen de compra
- Integración con WhatsApp

### 4. **Editor de Diseños Personalizado**
- Seleccionar tipo de prenda (camiseta, short, buzo)
- Elegir colores personalizados
- Agregar texto personalizado
- Previsualización en tiempo real
- Guardar diseños para futuro
- Agregar diseños personalizados al carrito

### 5. **Formulario de Contacto**
- Formulario de contacto integrado
- Enlaces a Instagram, WhatsApp y ubicación
- Información de ubicación en Mataderos

### 6. **Integración WhatsApp**
- Botón de contacto directo
- Envío automático del carrito por WhatsApp
- Conversación directa con el equipo de Giallo

### 7. **Gestión de Datos Locales**
- Carrito persistente con localStorage
- Guardado de diseños personalizados
- Datos almacenados localmente en el navegador

## Tecnologías

- **Frontend**: HTML5, CSS3, Tailwind CSS
- **Interactividad**: JavaScript Vanilla
- **Almacenamiento**: LocalStorage
- **Iconos**: Emojis Unicode

## Estructura

